# What Was Realized by What Tools

*   **Backend**: Next.js 16 (API Routes), Google Vertex AI (GenAI), and Firebase Admin SDK.
*   **Database**: Local JSON State (Builds) and Firestore (User Data) for real-time tracking.
*   **Frontend**: React 19 (Server Components) with Tailwind CSS, Framer Motion, and Recharts.
*   **Deployment**: Hybrid setup using Netlify (Web App) and Local WSL2 / Docker (Build Engine).
*   **Environment**: Windows Subsystem for Linux (Ubuntu) providing the Kernel interface for LFS.
