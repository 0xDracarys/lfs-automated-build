# Vim Masterclass Guide

Configure the default text editor.

## 1. Configuration (.vimrc)
```vim
syntax on
set number
set tabstop=4
```

## 2. Command Reference
- `:wq` — Save and quit
- `:q!` — Quit without saving
- `u` — Undo change
